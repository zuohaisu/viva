# Viva v0.3.1

This patch release contains the changes merged into `main` after v0.3.0.

## Added

- **Workbench chrome**: a herdr-style workbench with a sidebar, command
  palette, shared pane borders, and a client-version indicator in the status
  bar.

## Fixed

- Pane resizing now checks the minimum size of the pane being kept, and
  surfaces rollback failures instead of hiding them.
- Workbench QA fixes improve viewport handling, diff overlays, and split
  guards.

## Release contents

The Rust package, lockfile, GitHub release tag, npm wrapper, and macOS platform
packages are versioned together as `0.3.1`. The existing tag-triggered release
workflow publishes the platform packages before the wrapper.
