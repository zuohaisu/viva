# Viva v0.2.1

## Added

- `viva update`: upgrade this installation to a newer stable version.
- `viva update --check`: check the installation's release channel without
  replacing the executable or installing packages.
- Global npm installations upgrade through npm at their original prefix,
  keeping the wrapper and platform package in sync.
- Standalone macOS installations use official GitHub Release artifacts:
  bounded HTTPS download, SHA-256 verification, version probe and atomic
  executable replacement. Failed native validation preserves the old binary;
  equal/older versions are not installed.

## First upgrade from v0.2.0 or earlier

Older binaries do not have `viva update`; install v0.2.1 once first:

```bash
npm install --global @zuohaisu/viva@0.2.1
viva --version
viva update --check
```

For standalone installations, download `viva-macos-arm64.tar.gz` (Apple
Silicon) or `viva-macos-intel.tar.gz` (Intel) and its SHA-256 checksum from
[this release](https://github.com/zuohaisu/viva/releases/tag/v0.2.1).

## Safety and limitations

- Updates do not open/migrate VIVA_HOME, alter member/task/history records,
  stop agents or restart servers. Activate the installed server explicitly
  with `viva server-restart`, then reconnect the TUI.
- Native updates replace only the executable; refresh bundled Pi extension
  sources separately if needed. Checksums provide integrity, not an
  independent publisher signature.
- Local npm installs update with `npm install @zuohaisu/viva@latest` inside
  their project. npm owns its installation/failure behavior; native atomic
  replacement guarantees do not apply to npm package installation.
- No sudo, automatic background upgrades or overwrite of Cargo build outputs.
